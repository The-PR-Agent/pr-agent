## Início rápido {#quick-start}
Revise um pull request direto do terminal. Você só precisa de uma chave da OpenAI e de um token do GitHub.

```bash
docker run --rm -it \
  -e OPENAI__KEY=<your_openai_key> \
  -e GITHUB__USER_TOKEN=<your_github_token> \
  pragent/pr-agent:latest --pr_url <pr_url> review
```

<div className="pra-cta-row">

[Instale nos seus repositórios](./installation/index.md) [Outras formas de rodar localmente](./installation/locally.md)

</div>

Já instalou? Comente `/help "sua pergunta"` em um pull request e o PR-Agent responde a partir desta documentação.
