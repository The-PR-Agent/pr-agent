## Inicio rápido

Revisa un pull request desde tu terminal. Solo necesitas una clave de OpenAI y un token de GitHub.

```bash
docker run --rm -it \
  -e OPENAI__KEY=<your_openai_key> \
  -e GITHUB__USER_TOKEN=<your_github_token> \
  pragent/pr-agent:latest --pr_url <pr_url> review
```

<div className="pra-cta-row">

[Instálalo en tus repositorios](./installation/index.md) [Otras formas de ejecutarlo en local](./installation/locally.md)

</div>

¿Ya lo tienes instalado? Comenta `/help "tu pregunta"` en un pull request y PR-Agent responde a partir de esta documentación.
