## Overview

Runs /review, whose findings can carry committable code fixes.

:::note
`/improve` and `/improve_code` run [`/review`](./review.md) as of 0.51, with a one-line notice under the review heading.
A command list that names both runs a single review. Findings that carry a fix are described in
[Fixes and committable suggestions](./review.md#fixes-and-committable-suggestions).
:::
